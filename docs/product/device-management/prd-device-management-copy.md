# Device Management PRD — error & state copy

Companion to [prd-device-management.md](prd-device-management.md): the shipping copy for every state that PRD names.
Each `E<n>` ID is the contract between a state and the rows that cite it; IDs never renumber. The rules that govern this table — the Cataloger's vocabulary, the stable-identity rule, the Placeholders rule, the reuse of a state's copy by confirmations and warn-level presentations — stay in that PRD's [§7](prd-device-management.md#7-error--state-copy), and the Status column here holds a value from that PRD's [Legend](prd-device-management.md#legend). This table is a P0 requirement. A state whose name is marked ‹P1› does not appear until its own rows land; a marked action inside an unmarked state is withheld until then, the state showing without it and its body standing as guidance — that PRD's P1-seam convention ([R4.4](prd-device-management.md#4-pre-flight-device-health)). Where a marked state carries the only exit from an unmarked loop, that exit stands as guidance in the loop's own state until the marked state lands — the sentence "You can come back to this any time from the device panel."
