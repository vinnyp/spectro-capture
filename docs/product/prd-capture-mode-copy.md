# Capture Mode PRD — error & state copy

Companion to [prd-capture-mode.md](prd-capture-mode.md): the shipping copy for every state that PRD names.
Each `E<n>` ID is the contract between a state and the rows that cite it; IDs never renumber. The Labels and Placeholders rules that govern this table stay in that PRD's [§12](prd-capture-mode.md#12-error--state-copy), and the Status column here holds a value from that PRD's [Legend](prd-capture-mode.md#legend). Actions marked ‹P1› arrive with the P1 rows (fence F47); until then the state shows without them and its body stands as guidance, as the device PRD's P1 convention. A state whose name is marked ‹P1› does not appear until its own rows land; a marked action inside an unmarked state is withheld until then. A state whose name carries another PRD's name ([E29](#error--state-copy)) arrives with that PRD.

## Error & state copy

The shipping copy for every error, waiting, choice, and confirmation state in this PRD, written in the Cataloger's vocabulary: plain language, names the recovery, never SDK-speak. Every state is a distinct named state whose identity is stable even when its wording changes, so behaviour can be asserted independently of copy ([R11.12](prd-capture-mode.md#11-demo-device-and-verifiability)). Every promise made below is backed by a requirement row in the PRD, except a state this PRD hands over whole ([E29](#error--state-copy)). Halt copy is the [device PRD §7](prd-device-management.md#7-error--state-copy)'s and is not restated here.
