# Data Foundation PRD — error & state copy

Companion to [prd-data-foundation.md](prd-data-foundation.md): the shipping copy for every state that PRD names.
Each `E<n>` ID is the contract between a state and the rows that cite it; IDs never renumber. The Status column holds a value from that PRD's [Legend](prd-data-foundation.md#legend). A state whose name is marked ‹P1› does not appear until its own rows land — or, where the sentence names it, another PRD's row, as [E8](#error--state-copy)'s and [E14](#error--state-copy)'s full-history sentence waits on [the export PRD's R1.3](../export/prd-data-export.md#1-what-the-export-contains) — and a marked action or sentence inside an unmarked state is withheld until then — the P1-seam convention the sibling PRDs use; a sentence marked ‹until P1› ships now and is withdrawn when the ‹P1› sentence it stands in for — the undo sentence in [E8](#error--state-copy) and [E14](#error--state-copy), and the full-history sentence there for the marked export sentences — appears; a sentence marked ‹OQ 14› is withheld until that question closes, and a state whose name is marked ‹floor› does not appear until a release raises the oldest file version the app upgrades ([R5.7](prd-data-foundation.md#5-migration-and-compatibility)). A marker leads the whole sentence it withholds and trails the whole action; it never sits inside one. The collection-unavailable state is the [capture PRD's E26](../capture-mode/prd-capture-mode-copy.md#error--state-copy)'s and the halt and pre-flight states are the [device PRD's](../device-management/prd-device-management-copy.md#error--state-copy); neither is restated here. The four export states — E6, E7, E17 and E18 — moved to [the export PRD's copy file](../export/prd-data-export-copy.md#error--state-copy) as its E1–E4 under fence F30 with no wording changed, and those numbers are retired here.

**Placeholders.** ⟨…⟩ stands for something filled in when the state is shown: ⟨code⟩ a Swatch Code, ⟨collection⟩ a collection's name, ⟨n⟩ a count of items or readings, ⟨size⟩ a file size, ⟨path⟩ a file location, ⟨version⟩ an app or file version, ⟨date⟩ a date. A count that would be zero, or a phrase naming something that is not there, is never shown as "0" or as a claim: the phrase or clause it governs is dropped with the conjunction or punctuation that joined it, and the rest of the sentence stands; a sentence, list line or action that exists only for that phrase, or that would not stand without it, is left out. A sentence carrying a count agrees with it — "1 reading", "⟨n⟩ readings"; and a named provisional constant renders as the number it currently holds, never as its name.
