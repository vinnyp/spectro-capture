# Data Foundation PRD — error & state copy

Companion to [prd-data-foundation.md](prd-data-foundation.md): the shipping copy for every state that PRD names.
Each `E<n>` ID is the contract between a state and the rows that cite it; IDs never renumber. The Status column holds a value from that PRD's [Legend](prd-data-foundation.md#legend). A state whose name is marked ‹P1› does not appear until its own rows land, and a marked action or sentence inside an unmarked state is withheld until then — the P1-seam convention the sibling PRDs use; a sentence marked ‹OQ 14› is withheld until that question closes, and a state whose name is marked ‹floor› does not appear until a release raises the oldest file version the app upgrades ([R5.7](prd-data-foundation.md#5-migration-and-compatibility)). A marker leads the whole sentence it withholds and trails the whole action; it never sits inside one. The collection-unavailable state is the [capture PRD's E26](../capture-mode/prd-capture-mode-copy.md#error--state-copy)'s and the halt and pre-flight states are the [device PRD's](../device-management/prd-device-management-copy.md#error--state-copy); neither is restated here.

**Placeholders.** ⟨…⟩ stands for something filled in when the state is shown: ⟨code⟩ a Swatch Code, ⟨collection⟩ a collection's name, ⟨n⟩ a count of items or readings, ⟨size⟩ a file size, ⟨path⟩ a file location, ⟨version⟩ an app or file version, ⟨date⟩ a date. A sentence whose count would be zero is left out rather than shown as "0"; a sentence carrying a count agrees with it — "1 reading", "⟨n⟩ readings"; and a named provisional constant renders as the number it currently holds, never as its name.
